# 宾果 Bingo Đồ ăn

Game Bingo từ vựng đồ ăn tiếng Trung cho học sinh. Chạy ngay trên trình duyệt, chỉ một file `index.html`.

**Từ vựng:** 米饭 mǐfàn · 面条 miàntiáo · 桃子 táozi · 牛奶 niúnǎi · 水 shuǐ · 蛋糕 dàngāo · 香蕉 xiāngjiāo · 黄瓜 huángguā · 胡萝卜 húluóbo

## Ba chế độ

- **Chơi**: bảng 3×3 xáo ngẫu nhiên. Máy đọc từ bằng giọng tiếng Trung, học sinh bấm đúng hình để đóng dấu 好. Đủ một hàng ngang, dọc hoặc chéo là BINGO. Chọn "Thầy cô gọi" nếu giáo viên đọc từ trên lớp.
- **Màn hình gọi từ**: dành cho máy chiếu. Gọi từ, nghe lại, hiện đáp án; bảng nhỏ bên dưới giúp kiểm tra học sinh hô BINGO có đúng không. Phím tắt: `Space` gọi từ, `R` nghe lại, `Enter` hiện đáp án.
- **In thẻ**: tạo nhiều thẻ với thứ tự khác nhau, in 4 thẻ một trang A4.

Mục "Thẻ hiện" đổi độ khó: chỉ hình → hình + chữ Hán → chữ Hán + pinyin → chỉ chữ Hán.

## Chạy

Mở `index.html` bằng Chrome, Edge hoặc Safari. Giọng đọc dùng Web Speech API; máy cần có giọng tiếng Trung (zh-CN).
